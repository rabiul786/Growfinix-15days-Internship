# Task 2: Data Structures and File Handling

A small program that stores student details in a dictionary and saves them to JSON, CSV and text files.

- `student_data.py` - menu program (add, view, save)
- `collections_demo.py` - examples of list, tuple, dictionary and set

## How to run

```
python student_data.py
python collections_demo.py
```

## Files created

- `students.json` - loaded automatically when the program starts
- `students.csv`
- `students.txt`

## Sample output

```
Roll No   Name        Age   Course
----------------------------------------
101        Rahim       20    B.Tech
102        Ayesha      21    B.Sc
```
