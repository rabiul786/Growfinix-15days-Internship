# Python Beginner Projects

This repository contains three small Python projects that I created while learning and practicing Python programming.

The main goal of these projects was to improve my understanding of Python basics and learn how to apply them to simple real-world problems.

## Projects

### 1. Simple Calculator

I created a basic calculator that can perform four mathematical operations.

**Features:**

* Add two numbers.
* Subtract two numbers.
* Multiply two numbers.
* Divide two numbers.
* Handle division by zero.
* Check invalid user input.

### 2. Number Guessing Game

In this game, the computer randomly selects a number between 1 and 100, and the user has to guess it within 7 attempts.

**Features:**

* Generate a random number.
* Give hints if the guess is too high or too low.
* Check whether the entered number is valid.
* Allow the user to play again.

### 3. Student Marks Calculator

This program takes a student's name and marks in different subjects and calculates the final result.

**Features:**

* Take student details as input.
* Calculate total marks.
* Calculate percentage.
* Assign grades based on percentage.
* Display whether the student has passed or failed.

**Grading System:**

| Percentage   | Grade |
| ------------ | ----- |
| 90 and above | A+    |
| 80–89        | A     |
| 70–79        | B     |
| 60–69        | C     |
| 40–59        | D     |
| Below 40     | F     |

## How to Run

First, make sure Python is installed on your computer.

Clone this repository:

```bash
git clone https://github.com/rabiul786/Growfinix-15days-Internship.git
```

Open the project folder and run any of the following commands:

**Simple Calculator**

```bash
python calculator.py
```

**Number Guessing Game**

```bash
python number_guessing_game.py
```

**Student Marks Calculator**

```bash
python student_marks_calculator.py
```
