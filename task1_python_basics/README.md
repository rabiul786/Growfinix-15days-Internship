# Task 1: Python Fundamentals

Three small programs to practise variables, loops, conditions, functions and input/output.

- `calculator.py` - add, subtract, multiply, divide
- `guessing_game.py` - guess the number in 7 attempts
- `marks_calculator.py` - total, percentage and grade for a student

## How to run

```
python calculator.py
python guessing_game.py
python marks_calculator.py
```

## Sample output

```
Enter student name: Rahim
How many subjects? 3
...
--- Result for Rahim ---
Total marks: 255.0 out of 300
Percentage: 85.0 %
Grade: A
Result: Pass
```
